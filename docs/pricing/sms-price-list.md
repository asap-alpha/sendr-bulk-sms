# SMS Price List

**Rate: GHS 0.05 per segment.**  Every table below is that one number multiplied out.

Billing is per *segment*, not per message. A message longer than one segment is billed as
many messages. Encoding decides where the boundaries fall:

| Encoding | When it applies | Single segment | Per segment when split |
|---|---|---:|---:|
| GSM-7 | Every character is in the GSM 03.38 alphabet | 160 chars | 153 chars |
| UCS-2 | Any one character is outside it (emoji, curly quotes, most accents, non-Latin) | 70 chars | 67 chars |

A single emoji anywhere in the body switches the **whole** message to UCS-2 and roughly
doubles the bill. The characters `^ { } \ [ ~ ] | €` stay GSM-7 but each count as 2.

## 5. Unit economics quick reference

All figures in GHS.

| Volume | 1 seg | 2 seg | 3 seg | 4 seg | 5 seg | 10 seg |
|---|---:|---:|---:|---:|---:|---:|
| Per recipient | 0.05 | 0.10 | 0.15 | 0.20 | 0.25 | 0.50 |
| Per 100 | 5.00 | 10.00 | 15.00 | 20.00 | 25.00 | 50.00 |
| Per 1,000 | 50.00 | 100.00 | 150.00 | 200.00 | 250.00 | 500.00 |
| Per 10,000 | 500.00 | 1,000.00 | 1,500.00 | 2,000.00 | 2,500.00 | 5,000.00 |
| Per 100,000 | 5,000.00 | 10,000.00 | 15,000.00 | 20,000.00 | 25,000.00 | 50,000.00 |
| Per 1,000,000 | 50,000.00 | 100,000.00 | 150,000.00 | 200,000.00 | 250,000.00 | 500,000.00 |

Rules of thumb:

- GHS 1.00 = 20 segments.
- GHS 50.00 = 1,000 single-segment messages.
- 1,000 recipients costs GHS 50.00 per segment of message length.
- Each extra segment adds 100% of the single-segment cost — a 3-segment message is 3× a 1-segment one.

## Notes

- Rate source: `SMS_RATE` in [src/lib/sms.ts](../../src/lib/sms.ts).
- At runtime the authoritative rate comes from `GET /api/sms/billing/status` via
  [src/stores/pricing.ts](../../src/stores/pricing.ts). If the backend returns a different
  `pricePerPart`, every figure here scales linearly — multiply by `newRate / 0.05`.
- Segment counts follow `analyzeMessage()` in the same file: astral-plane emoji count as 2
  UCS-2 units, GSM extension characters count as 2 GSM-7 units.
- Costs are billed on segments *sent*. Failed or undelivered messages are not modelled here.
